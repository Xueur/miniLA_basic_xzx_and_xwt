# EGO1 数码管分组修复说明

本版修复了 `src/rtl/seven_seg.v` 中两组段选总线接反的问题。

- `LED_BIT1`～`LED_BIT4` 对应第一组段线 `CA0`～`CG0`，由 `dig_seg` 驱动。
- `LED_BIT5`～`LED_BIT8` 对应第二组段线 `CA1`～`CG1`，由 `dig_seg1` 驱动。
- 位选与段选均为高电平有效。

修复前可能只在第一位和第五位看到异常数字。修复后 Trace 程序最终应稳定显示：

```text
25000025
```

请用本版目录重新创建 Vivado 工程并重新生成比特流，不能继续下载旧 `.bit`：

```tcl
cd {D:/miniRV_trace_board_v2/miniRV_complete}
source create_trace_board_project.tcl
source run_seven_seg_board_tb.tcl
close_sim
source run_trace_board_tb.tcl
close_sim
source build_trace_board_bitstream.tcl
```

下载：

```text
output/miniRV_trace_board_50MHz.bit
```

下载后按下 S6 约一秒再松开。按住时显示全零正常，松开后最终结果应为 `25000025`。
